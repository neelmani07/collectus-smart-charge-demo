# smart-charge-demo

Tamara-styled demo UI for Collectus Smart Autocharge.

## Screens

- **Shop** — partner products, Pay in 3/4 checkout
- **My payments** — installment timeline per purchase, Pay now
- **Smart activity** — always-charge vs AI decision after repayment

Brand cues from public Tamara guidelines: Lavender `#9600F1`, Zingy `#5300BA`, Dreamy/Light lilac accents.

## Quick start

```bash
cd smart-charge-demo
cp .env.example .env
npm install
npm run dev
```

Requires backend at `VITE_API_BASE_URL` (default `http://127.0.0.1:8000`).
